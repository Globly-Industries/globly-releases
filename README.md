# Globly releases

Android builds of **Globly**, a map-based app for sharing photos, videos, audio and text from
places around the world.

This repo has no code, only [releases](https://github.com/Globly-Industries/globly-releases/releases).
They are built and signed automatically.

## Install

1. On your Android phone, open the [latest release](https://github.com/Globly-Industries/globly-releases/releases/latest).
2. Download the `.apk` file under **Assets**.
3. Open it and allow installs from your browser when Android asks.

## Updates

The app checks this repo when it starts and offers new versions itself. You can also check from
**Profile -> Check for updates**. Updates install over the existing app and keep your sign-in.
